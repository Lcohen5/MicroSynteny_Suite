No. Your browser opens the file and draws the figures on this computer. The page does not send the table or the figures anywhere, and it keeps working with the internet turned off. Nothing is kept after you close the tab.

      

      

        
A table from the MicroSynteny Table Builder (schema v7): your own, or the merged table for a class, which ends in _merged.tsv.

        
If you drop several tables for the same target gene, or a folder of them, the page merges them first. It follows the same rules as the suite's merge step and shows the same merge report.

      

      

        
One with every species in the table, then one for each subgenus and one for each species group, wherever the table has at least two species to compare. Subgroups are off to begin with; turn them on under Options.

        
In a subset figure, species that are neighbours in that figure are joined by ribbons even when other species sit between them in the full figure.

      

      

        
    
          
  • Each row is a species and each arrow is a gene, pointing the way it is transcribed. Every species is turned so the target gene points right, with upstream on the left. A species marked (- strand) has its target on the minus strand.
    • 
          
  • Genes nested inside another gene sit in a row of tiles above it.
    • 
          
  • Ribbons join the same gene name in neighbouring species: teal for the same slot and direction, blue for a different slot, magenta and twisted for a different direction. A dashed ribbon reaches across species that lack the gene.
    • 
        

      

      

        
PNG is a picture, for slides and posters. SVG and PDF are drawings that stay sharp at any size. The lettering in the SVG is real text, so labels can be changed in Inkscape or Illustrator.

      

      

        
Yes. The place of every arrow, tile, ribbon and label, and every colour, is checked against comparative_synteny_plot.R (version 16). A few things differ on purpose:

        
    
          
  • The two legends always come in the same order, and a long gene legend wraps into columns instead of running off the page.
    • 
          
  • A species whose target sits inside another gene is still turned to face its target. Version 16 of the R script leaves such a species unturned, which makes its whole row look inverted when the target is on the minus strand.
    • 
          
  • A gene nested inside a gene that is itself nested is drawn; the R script stops on that table.
    • 
          
  • A table with a strand that is not + or - is refused, with the rows named; the R script draws such a gene pointing left.
    • 
          
  • Lettering is drawn with this computer's Helvetica or Arial.
    • 
        

      

      

        
The Python Table Builder, the merge step and the R script are at github.com/Lcohen5/MicroSynteny_Suite. A first version of the Table Builder is also on this page, under Table Builder at the top.
